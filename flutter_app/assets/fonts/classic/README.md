# Classic font group

Traditional book-style — full serif everywhere.

## Bundled files (variable fonts)

| File | Family in pubspec | Role |
|------|-------------------|------|
| `PlayfairDisplay.ttf` | `ClassicHeading` | Display serif heading |
| `SourceSerif4.ttf` | `ClassicBody` | Reading-grade serif body |
| `JetBrainsMono.ttf` | `ClassicMono` | Mono / code |

> **Note:** The README originally referenced "Source Serif Pro". Google relabeled the family as "Source Serif 4" in 2022. The bundled file uses that newer name; the pubspec family alias `ClassicBody` is unchanged so calling code stays the same.
