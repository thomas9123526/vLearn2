# Classic font group

Traditional book-style — full serif everywhere.

Drop these `.ttf` files in this folder (then uncomment the `ClassicHeading` / `ClassicBody` / `ClassicMono` blocks in [`pubspec.yaml`](../../../pubspec.yaml)):

- `PlayfairDisplay-Regular.ttf`
- `PlayfairDisplay-Bold.ttf`
- `SourceSerifPro-Regular.ttf`
- `SourceSerifPro-Bold.ttf`
- `JetBrainsMono-Regular.ttf`

Sources (OFL 1.1):

| Family | URL |
|--------|-----|
| Playfair Display | https://github.com/clauseggers/Playfair |
| Source Serif Pro | https://github.com/adobe-fonts/source-serif |
| JetBrains Mono | https://github.com/JetBrains/JetBrainsMono |
