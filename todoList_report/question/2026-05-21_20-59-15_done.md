## Stage 6 now starts

ECDSA signing on a single API surface. The plan:

1. Load admin's `signing.cert_path` (`admin.crt`, X.509 PEM) via `mbedtls_x509_crt_parse_file`.
2. Load admin's `signing.key_path` (`admin.key`, EC PEM) via `mbedtls_pk_parse_keyfile`.
3. Pack writes `[Header][Manifest][Data]` as today, then **appends the admin cert PEM as section [4]**.
4. Compute SHA-256 over `header ‖ manifest ‖ data ‖ cert`.
5. Sign that digest with the admin's EC key via `mbedtls_pk_sign` (DER-encoded ECDSA signature).
6. **Append signature as section [5]**.
7. Patch `cert_len`/`cert_offset`/`sig_len`/`sig_offset` in the header.

Stage 6 also extends `config.json` parsing to require `signing.cert_path` + `signing.key_path` when `pack_mode.encrypt != "none"` or any production flag. For Stage 6 itself I'll make signing **optional** (config can omit signing block → unsigned debug pack; if present → must succeed end-to-end).
