## Known dual-mode caveat

PowerShell doesn't pipe stdout from a WIN32-subsystem .exe synchronously. CLI mode works (exit codes correct) but to see output you need `Start-Process -Wait -NoNewWindow ...` or `cmd /c start /wait`. Documented in README. If CLI becomes a primary use case later, we'll add a separate CONSOLE-subsystem `DataManage_cli.exe` target.
