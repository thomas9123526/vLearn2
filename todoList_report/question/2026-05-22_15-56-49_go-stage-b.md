## What Stage B added

The Flutter installer now reads the `group`/`unpack_phase` Stage A wrote into each `.dat` manifest, and filters by phase:

- **`readPackManifest(packPath)`** — cheap peek: reads only the 64-byte header + plaintext manifest, no decrypt/verify/whole-file-read. Lets the installer learn a pack's phase before deciding to unpack it.
- **`installPending({phase = 'splash'})`** — for each `.dat`: peek manifest → wrong phase ⇒ `deferred` (untouched, no hash) → right phase ⇒ existing hash/cache/unpack flow.
- **New `deferred` status** — distinct from `failed`, so the splash treats deferred packs as a non-event.
- **Splash pass** unpacks only `unpack_phase: splash` packs; `on-demand` packs come back `deferred`, waiting for Stage C.
