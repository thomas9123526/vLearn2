## What Stage C added

The complete on-demand unpack path:

- **`unpack()` per-file progress** — optional `onFileProgress(done, total)` callback.
- **`installGroup(group, {onProgress})`** — unpacks every not-yet-installed `.dat` in a named group, streaming an overall 0.0–1.0 fraction; checkpoints after each pack so it resumes if interrupted.
- **`DataPackGroupController`** — Riverpod `Notifier` exposing `ensureGroup("speech")`. Runs the unpack on a **background isolate** (`Isolate.spawn` + `ReceivePort`) so it streams progress without freezing the UI — the right tool since `Isolate.run` can't stream.
- **`DataPackProgressView`** — reusable stateless 0–100% widget (bar + `NN%` + status line).
