## How to use it now

GUI:
1. Launch `build-x64\bin\DataManage.exe`.
2. **File → Open Config…** → pick a `config.json`. Status bar shows bundle count.
3. **Pack → Run Pack…** → produces `<output_dir>/<name>.ddp` per bundle.

CLI:
```powershell
Start-Process -FilePath .\build-x64\bin\DataManage.exe `
              -ArgumentList 'pack', '--config', 'config.json' `
              -NoNewWindow -Wait
```
