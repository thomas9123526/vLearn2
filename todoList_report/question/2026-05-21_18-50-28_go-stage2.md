## `.ddp` Header — pinned at 64 bytes

```cpp
struct Header {              // offset / size
    uint32_t magic;          //  0  "DDDP"
    uint32_t version;        //  4
    uint32_t flags;          //  8  bit 0 = compressed, bit 1 = encrypted
    uint32_t manifest_len;   // 12
    uint64_t manifest_offset;// 16
    uint64_t data_len;       // 24
    uint64_t data_offset;    // 32
    uint32_t sig_len;        // 40
    uint64_t sig_offset;     // 44
    uint32_t cert_len;       // 52
    uint64_t cert_offset;    // 56
};                           // total 64
static_assert(sizeof(Header) == 64);
```

Stored little-endian. Both Windows (x86/x64) and Android (ARM) are LE — no byte-swapping at either end.

## Manifest validation rules (enforced on read)

- `rel_path` / `out_folder` must be **relative** (no `/`, no `\`, no `C:`).
- No path segment may be `..` after splitting on `/` or `\`.
- `sha256_hex` must be exactly 64 hex chars.
- `compression` ∈ `{"none", "zstd"}`, `encryption` ∈ `{"none", "aes-256-gcm"}`.
