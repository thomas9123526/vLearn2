## To wire it into your splash screen

```dart
final outcomes = ref.watch(installPendingDataPacksProvider);
return outcomes.when(
  loading: () => const SplashScreen(),  // your existing splash
  error:   (e, _) => DataPacksUnavailableScreen(error: e.toString()),
  data:    (list) {
    final failed = list.where((o) => o.status == DataPackInstallStatus.failed);
    return failed.isEmpty ? const HomeScreen() : DataPacksFailedScreen(failed: failed);
  },
);
```

## For your real deployment

Before shipping for real:

1. **Run `datamanage/ca/make_root_ca.ps1` on an offline machine.** Save `root_ca.key` somewhere very safe.
2. **Run `issue_admin_ca.ps1 -Name <you>`** to issue your real admin sub-CA.
3. **Copy the real `admin.key` → `flutter_app/assets/datamanage/admin.key`** (gitignored, per-build).
4. **Copy the real `root_ca.crt` → `flutter_app/assets/datamanage/root_ca.crt`** (committed).
5. **Build DataManage.exe**, use it to produce real `.ddp` files for your model + font bundles.
6. **USB-transfer the `.ddp` files** to `/sdcard/룡마/가상외국어회화/datapacks/` on the device.
7. **Launch the app** — the installer unpacks on first run, caches on subsequent runs.

The dev artefacts (alice keys, test root CA) under `datamanage/ca/issued/` should be wiped between dev and production.
