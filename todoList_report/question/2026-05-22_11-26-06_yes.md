## How to use it

In `config.json`, the top-level `pack_mode` is the default. Any bundle can override it with its own `pack_mode` block:

```jsonc
{
  "version": 1,
  "pack_mode": { "compress": "zlib", "encrypt": "none" },   // default for all
  "signing": { "cert_path": "...", "key_path": "..." },
  "bundles": [
    { "name": "out_model", "source_dir": "...", "out_folder": "models" },
      // ← no pack_mode → inherits zlib/none → fast unpack

    { "name": "out_secret", "source_dir": "...", "out_folder": "secret",
      "pack_mode": { "compress": "zlib", "encrypt": "aes-256-gcm" } }
      // ← own pack_mode → compressed + encrypted
  ],
  "output_dir": "./output"
}
```

**Inheritance rules:**
- No `pack_mode` in a bundle → inherits the whole global.
- A `pack_mode` block that names only `compress` → `encrypt` inherits the global (and vice versa).
