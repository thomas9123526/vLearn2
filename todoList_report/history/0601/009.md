# Task 009 — User Image Upload

## What was done

The upload pipeline was already implemented end-to-end; this task wired up
the missing admin panel display.

### Already existing (no changes needed)
- `POST /users/avatar` — NestJS endpoint that stores to `uploads/avatars/<user_id>.<ext>`
  and saves `avatar_url` + `avatar_storage_key` in `vl_user_info`.
- Flutter `edit_profile_dialog.dart` — image picker (camera / gallery), resizes to
  1024 px / quality 85, calls `usersApiProvider.uploadAvatar()`, refreshes profile.

### Modified files
- `backend/src/admin/admin-users.controller.ts` — `GET /admin/users/:id` now includes
  `avatar_url` and `avatar_emoji` in the response.
- `admin_panel/src/app/(dashboard)/users/page.tsx` — `UserDetailsModal` now shows:
  - Circular avatar image (if `avatar_url` set) or large emoji fallback in a circle.
  - User's display name and email beneath the avatar at the top of the modal.
