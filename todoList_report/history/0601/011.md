# Task 011 — STT/TTS Switching Guide

## What was done

Created `docs/combinestt/README.md` — a complete guide for switching from
sherpa-onnx to a Java native STT/TTS library, or combining both.

### Contents of the guide

1. **Current architecture** — abstract interfaces (`SpeechToTextService`,
   `TextToSpeechService`) and concrete sherpa-onnx implementations.
2. **Java native library** — what method/event channel signatures to confirm.
3. **How to add the native implementation** — full skeleton code for
   `NativeSttService` and `NativeTtsService` implementing the same interfaces.
4. **Switching the provider** — one-line change in `main.dart`.
5. **Combining both** — `FallbackSttService` wrapper that tries sherpa-onnx
   first and falls back to native if the model is not installed.
6. **Checklist** — items to verify after switching.
7. **File map** — which files to touch.

### Why this approach
No changes to the rest of the app are required when switching — the conversation
screen, tutor avatar, and mic button all use the abstract interfaces only.
