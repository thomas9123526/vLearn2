# Task 010 — Rename /personas/ → /teachers/ + Gender-based TTS

## What was done

### API endpoint rename

| Before | After |
|--------|-------|
| `GET /personas` | `GET /teachers` |
| `GET /personas/:id` | `GET /teachers/:id` |
| `GET /admin/personas` | `GET /admin/teachers` |
| `PATCH /admin/personas/:id` | `PATCH /admin/teachers/:id` |
| `DELETE /admin/personas/:id` | `DELETE /admin/teachers/:id` |
| `POST /admin/personas/:id/restore` | `POST /admin/teachers/:id/restore` |
| `POST /admin/personas/:id/image` | `POST /admin/teachers/:id/image` |

### Modified files
- `backend/src/personas/personas.module.ts` — `@Controller('teachers')`.
- `backend/src/admin/admin-personas.controller.ts` — `@Controller('admin/teachers')`.
- `flutter_app/lib/core/api/app_apis.dart` — `PersonasApi` calls `/teachers`.
- `admin_panel/src/app/(dashboard)/layout.tsx` — nav href `/teachers`, label "Teachers".
- `admin_panel/src/app/(dashboard)/teachers/` — renamed from `personas/`; all internal
  links, query keys, and API paths updated to `/admin/teachers`.

### Gender field
Already present in `PersonaEntity` (`'female' | 'male' | 'neutral'`).
Admin panel edit form already has the gender dropdown.

### TTS by gender
- `flutter_app/lib/features/conversation/widgets/tutor_mode_view.dart`:
  Added `_pickVoiceForGender(voices, gender)` method.
  When `persona.voiceId` is null, it searches the available voice list for a name
  fragment matching the persona's gender (female: amy, jenny, linda…; male: alan,
  james, john…) before falling back to index 0.
