# Task 012 — App Usage Analytics + User Report Function + Admin Toggle

## What was done

### New entity
`backend/src/database/entities/user-report.entity.ts` — `vl_user_reports` table:
- `id`, `user_id`, `type` (feedback/bug/other), `content`, `platform`, `app_version`, `created_at`

### Backend — user report endpoint
`POST /users/report` in `UsersController`:
- Authenticated (JWT required).
- Body: `{ type?, content, platform?, app_version? }`.
- Saves to `vl_user_reports` and returns `{ ok: true }`.

### Backend — admin analytics endpoints (extended AdminStatsController)
- `GET /admin/stats/usage` — sessions per platform (joined `vl_conversation_sessions` ↔ `users`) + network bytes per platform (`vl_user_network_stats` aggregated).
- `GET /admin/stats/reports` — paginated list of user reports; optional `?type=` filter.

### App-config flags (added to seed)
| Key | Default | Visible to app |
|-----|---------|----------------|
| `system.user_report_enabled` | `true` | ✓ |
| `system.usage_analytics_enabled` | `true` | — |

### Flutter
- `UsersApi.sendReport()` — `POST /users/report`.
- `SettingsScreen` — "Send feedback" tile added, gated by `system.user_report_enabled` flag.
- Inline dialog: type dropdown (Feedback / Bug / Other) + 2000-char message field.
  Shows success/error snackbar after submission.

### Admin panel — new pages
- `admin_panel/src/app/(dashboard)/usage/page.tsx` — two cards: sessions by platform
  (count + percentage share) and network traffic by platform (uploaded / downloaded bytes).
- `admin_panel/src/app/(dashboard)/reports/page.tsx` — table of user reports, filterable
  by type, click-to-expand for full message + metadata.
- Both added to sidebar nav under `analytics.view` permission.
