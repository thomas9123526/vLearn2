# 08 – Internationalization (i18n)

## 8.1 Supported Languages

| Code | Language | Font Override |
|------|----------|--------------|
| `en` | English | Plus Jakarta Sans (default) |
| `ko` | Korean (조선어) | Noto Sans KR |
| `zh` | Chinese (中文) | Noto Sans SC |

---

## 8.2 Flutter i18n Setup

### Package
- `flutter_localizations` (SDK) + `intl`
- ARB file format for compile-time safety

### Files
```
lib/l10n/
├── app_en.arb    # English (source of truth)
├── app_ko.arb    # Korean
└── app_zh.arb    # Chinese
```

### pubspec.yaml
```yaml
flutter:
  generate: true
  
# l10n.yaml (at project root)
# arb-dir: lib/l10n
# template-arb-file: app_en.arb
# output-localization-file: app_localizations.dart
```

### main.dart
```dart
MaterialApp(
  localizationsDelegates: AppLocalizations.localizationsDelegates,
  supportedLocales: AppLocalizations.supportedLocales,
  locale: ref.watch(localeProvider),
)
```

## 8.5 Font Handling for CJK

**File:** `lib/core/theme/app_typography.dart`

```dart
TextStyle uiFont(Locale locale) {
  if (locale.languageCode == 'ko') {
    return GoogleFonts.notoSansKr();
  } else if (locale.languageCode == 'zh') {
    return GoogleFonts.notoSansSc();
  }
  return GoogleFonts.plusJakartaSans();
}
```

## 8.6 Locale Provider

**File:** `lib/core/providers/locale_provider.dart`

```dart
@riverpod
class LocaleNotifier extends _$LocaleNotifier {
  @override
  Locale build() {
    final saved = db.appSettings.get('ui_language') ?? 'en';
    return Locale(saved);
  }
  
  Future<void> setLocale(String languageCode) async {
    await db.appSettings.set('ui_language', languageCode);
    await api.updateSettings(uiLanguage: languageCode);
    state = Locale(languageCode);
  }
}
```

- [ ] **8.6.1** Read from SQLite `app_settings` on init
- [ ] **8.6.2** Fall back to device locale if not set (but only if supported)
- [ ] **8.6.3** Sync to backend on change
