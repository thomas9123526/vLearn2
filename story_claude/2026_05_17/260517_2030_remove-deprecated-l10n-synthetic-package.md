## What this task did

## Decisions / call-outs

- **Did not touch the 55 "newer version available" packages.** Those are flagged by `pub get` as version-constraint-incompatible — bumping any of them is its own task (risky for `riverpod 2 → 3`, `freezed 2 → 3`, `go_router 14 → 17`, `drift`, `analyzer 6 → 13`, etc.). The build script doesn't fail on them, so they're noise, not blockers.
- **Didn't regenerate localization output.** Removing the key changes nothing about where files are generated — `output-dir: lib/l10n/generated` already pins that location. The existing `flutter_app/lib/l10n/generated/` tree (currently untracked) will be regenerated by the next build / pub get.
- **Build status unknown.** The pasted output cut off before `flutter build apk --debug` finished. If the build later failed, that's a separate task — the deprecation fix doesn't affect APK compilation.
