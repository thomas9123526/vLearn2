# Android minSdk reverted 26 → 24

## What changed

`flutter_app/android/app/build.gradle.kts` — `defaultConfig.minSdk`
set back to `24`. Reverses the previous commit (`6e1026d`) which had
raised it to 26.

The app's minimum supported platform is **API 24 (Android 7.0)**
again — which is also the plugin floor (`sqlite3_flutter_libs` and
`flutter_secure_storage` both require API 24+).

## Why

The admin asked to go back to "at least 24" — i.e. keep supporting
API 24/25 (Android 7.0 / 7.1) devices, not drop them.

## Note

The earlier `260522_163000_minsdk_26.md` story log is left in place
as the historical record of the 24→26 change; this file records the
revert. Net effect across the two commits: `minSdk` unchanged at 24.

No build run — `minSdk` is a manifest `uses-sdk` value, doesn't
affect compilation.
